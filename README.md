# نموذج عيادتي التفاعلي · مرجع بصري طبي أزرق وأبيض

افتح `index.html` بمتصفح حديث. الصفحة الرئيسية مستوحاة من إحساس الصورة المرجعية: مساحة بيضاء، درجات أزرق هادئة، رسم طبي أصلي، دعوة واضحة للحجز، وبطاقات خدمات. الأقسام المتاحة:

- **الحجوزات:** إنشاء حجز بتاريخ ووقت، تسجيل الوصول، إنهاء الزيارة أو إلغاؤها.
- **الدكاترة:** قائمة التخصصات والأسعار ومواعيد العمل، إضافة دكتور تجريبي وتبديل نشاطه.
- **المرضى:** بحث تجريبي وخط زمني للحجوزات وحالة الزيارة، من دون ملاحظات طبية.
- **الحسابات:** إضافة دخل أو مصروف وعرض ملخص يومي/صافي حسب تاريخ تختاره، بالجنيه المصري. هذا دفتر عيادة وليس حسابًا بنكيًا.
- **بوابة الدكتور:** تبديل حسابات العرض ومتابعة جدول الدكتور وتقدم الزيارات. هذه محاكاة وليست تسجيل دخول حقيقيًا.

بيانات المثال تبدأ في 13 نوفمبر 2026. الواجهة تحفظ التغييرات في ذاكرة الصفحة فقط، وتعود لبيانات البداية بعد إعادة التحميل. راجع `supabase/README.md` ومخطط SQL إذا كنت تجهز مشروع Supabase.

**حدود مهمة:** هذا تسليم واجهة أمامية وتجهيز مخطط قاعدة بيانات، وليس نظامًا جاهزًا للإنتاج. لم يُربط Supabase، ولم يُفعّل دخول حقيقي أو تخزين مستمر أو تحويلات بنكية. لا تدخل بيانات مرضى أو بيانات مالية حقيقية. يلزم كود التطبيق المنشور وإعدادات Supabase ثم اختبار الصلاحيات والنسخ الاحتياطية على بيئة اختبار قبل الإطلاق.
